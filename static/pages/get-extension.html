Get the extension

Add SAYNO to your browser.

The extension adds Card Guard and a safety rating for every page you open. It works in Chrome and Edge and takes about a minute. The Chrome Web Store version is coming soon; until then you can install it yourself in four steps.

Download the extension (zip)

Install it yourself

  1. 1

    Unzip it

    Right-click the downloaded file and choose Extract all (on a Mac, double-click it). Keep the folder somewhere permanent.

  2. 2

    Open the extensions page

    Go to chrome://extensions (or edge://extensions) and turn on Developer mode.

  3. 3

    Load it

    Click Load unpacked and pick the unzipped folder.

  4. 4

    Pin the shield

    Click the puzzle icon and pin SAYNO. That is it.

Try it straight away

With the extension installed, open the fake bank demo page: Card Guard will stop you. Then open the normal shop page and notice it is not blocked.

You can also use the message and website checks on this site with nothing installed. Prefer to see how it works first? Take the 60-second tour.
